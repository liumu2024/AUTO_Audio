# Sample Reference Analysis

Use this skill only for a sample explicitly selected by the user.

- Call `sample.analyze` to obtain real sample facts before describing its contents.
- Extract reusable pacing, structure, shot organization, transition, atmosphere and text-rhythm guidance.
- Keep sample content separate from candidate output materials: never place the sample video itself into the finished timeline unless it is independently supplied as a user material.
- When planning after analysis, cite the stored sample understanding rather than the filename or an earlier conversational guess.
- A missing sample blocks sample analysis only. It never blocks `text_to_video` or `material_brief`.
